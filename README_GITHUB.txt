GITHUB PAGES ДЭЭР БАЙРШУУЛАХ

1. Энэ хавтасны ДОТОРХ бүх файлыг repository-ийн үндсэн хэсэгт upload хийнэ.
2. index.html нь repository-ийн root дээр байх ёстой.
3. Settings → Pages → Deploy from a branch.
4. Branch: main, Folder: /(root), Save.
5. Үндсэн сайт: https://USERNAME.github.io/REPOSITORY/
6. Puzzle: https://USERNAME.github.io/REPOSITORY/puzzle/

ЧУХАЛ:
- Хавтсыг бүхлээр нь дотор нь дахин хавтас үүсгэж upload хийхгүй.
- assets, images, music, puzzle хавтаснууд index.html-тай нэг түвшинд байна.
